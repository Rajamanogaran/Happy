1. Install the local inference engine

            
pip install llama-cpp-python

              Run from the project directory. The download is approximately 480
              MB.
            

            
python scripts/download_model.py

            
3. Restart Happy

            
uvicorn happy.app:app --host 0.0.0.0 --port 8000

            

              Or set HAPPY_MODEL to your GGUF file path. CPU
              inference is used by default.
            

            

              Your notes and inference stay local. Web searches and page
              requests contact external services only when you request them. Set
              HAPPY_PASSWORD on the server to enable password protection. Use
              HTTPS and an authenticated reverse proxy for internet deployment.
